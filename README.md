# 보관검체 랙 배치 관리 (오프라인 웹앱)

보관검체의 실제 보관 위치(랙)를 바코드/QR 스캔으로 기록하는 현장용 웹앱입니다.

## 사용

`https://kong9365.github.io/qc-rack/` 로 접속하면 바로 사용할 수 있습니다.

- **첫 접속은 인터넷이 되는 곳에서** 한 번 열어야 합니다. 이때 앱과 기준 데이터가 기기에 저장됩니다.
- 그 뒤로는 신호가 없는 지하 보관소에서도 그대로 실행됩니다.
- 설치는 필요 없습니다. 즐겨찾기만 해두면 됩니다.

## 작업 순서

1. **랙 선택** — 구역 → 랙 → 단
2. **스캔** — 제품 라벨의 바코드(Code128/EAN 등) 또는 QR
3. **수량 입력** — 기준수량과 다른 랙 등록 내역을 확인하고 저장

한 검체가 여러 랙에 나뉘어 보관된 경우 수량이 합산되며, 기준수량과 비교해
`수량 일치 / 부족 / 초과` 로 자동 판정됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `app.js`, `styles.css` | 앱 본체 |
| `service-worker.js` | 오프라인 캐시 |
| `data/retention-samples.json` | 보관검체 기준 데이터 |
| `data/rack-master.json` | 랙 코드 마스터 |
| `vendor/jsQR.js` | QR 인식 (Apache-2.0) |
| `vendor/zxing.js` | 1차원 바코드 인식 (Apache-2.0) |

## 데이터 갱신

새 기준 엑셀을 받으면 관리 PC에서 `update_master.py` 로 `data/` 의 JSON을 다시 만든 뒤,
이 저장소에 덮어쓰기로 업로드합니다. 검체 ID는 승계되므로 기존 작업 데이터는 유지됩니다.
